# Zesov
> Zen yields sovereign simplicity.

Zesov is my personal engineering workspace.
The name comes from **Zen + Sovran**:
- **Zen** — cut noise, reduce complexity, focus on what matters.
- **Sovran** — sovereign ownership, self-directed building of systems and tooling.

This is a boundary-free space for technical exploration.
Prototypes, infrastructure, agents and experimental libraries live here.
I pursue clean, deliberate designs, and retain full control over every piece.
